# CarePath Website

This folder contains the CarePath Company Limited static website, transformed from the Vicodin medical HTML template using the supplied CarePath logo and company profile content.

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Home page – hero, about teaser, services, products, partners/clients preview, contact CTA |
| `about.html` | Company profile, 2023→2026 roadmap, mission, vision and values |
| `services.html` | The five integrated solutions |
| `products.html` | Full product ecosystem (7 categories) |
| `partners.html` | Strategic partners statement and partner brands |
| `clients.html` | Institutions served and client logos |
| `contact.html` | Contact form, address, phone, email and banking details |

## Branding

- Logo: `img/carepath-logo.png` (also used for favicon in `img/favicon.png` and `favicon.ico`)
- Primary brand colour: turquoise `#2BB3C1`
- Accent colour: mint green `#7ED6A6`
- Custom overrides: `css/carepath-custom.css`

## How to update

1. **Edit content**: Update the HTML files directly. The shared header, footer and page wrapper are generated by `generate_carepath.py` to keep all pages consistent.
2. **Change colours**: Edit `:root` variables in `css/carepath-custom.css`.
3. **Replace placeholder images**: Swap images in `img/` and update the `src` attributes in the HTML.
4. **Add partner/client logos**: Replace the text cards in `partners.html` and `clients.html` with `<img>` tags pointing to logo files.
5. **Contact form**: The form posts to `mail.php`. The recipient is set to `info@carepath.co.tz`. Update `mail.php` if the recipient address changes.

## Note

The old Vicodin eCommerce pages (shop, cart, checkout, account, etc.) are no longer linked from the main navigation and can be removed if no longer needed.
